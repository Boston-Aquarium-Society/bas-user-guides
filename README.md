# Boston Aquarium Society User Guides

User guide for members of the Boston Aquarium Society who manage the club's
web presence.

## Local Development

With `docker` and `docker-compose`:

```command
docker-compose up
```

and open http://localhost:8000

You can also run without docker with Python 3 installed:

```command
pip install -r requirements.txt
mkdocs serve
```

## Keeping it up to date

Whenever a club role or procedure changes, update the matching guide here.
See [CONTRIBUTING.md](CONTRIBUTING.md) for what that covers and what must
never be committed (secrets and member personal details).
