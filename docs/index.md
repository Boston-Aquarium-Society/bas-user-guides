# Home

This site contains instructions for how to maintain the Boston Aquarium
Society's web presence.

If you are adding content (new posts, calendar events, _etc._) to the main
{{ site.base_url }} website, navigate to the "**Content Maintainer**" tab
at the top of the site.

If you are maintaining our web presence, go to the **Webmaster** tab.

## Keeping these guides current

If you change how something works (a new service, a new person in a role, a
new fix for a problem), please update the guide that covers it, or open an
issue on [GitHub](https://github.com/Boston-Aquarium-Society/bas-user-guides/issues) saying what changed. Out-of-date
instructions are worse than none.
